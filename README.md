# Library Management System

## Overview
The Library Management System is a C++ academic project that manages books, users, and borrowing operations using Object-Oriented Programming (OOP) concepts.

The system allows librarians and customers to interact with the library through different functionalities such as managing books, searching, borrowing, and returning books.

---

## Features

### Librarian
- User authentication
- Add and remove books
- Add and remove customers
- Search for books
- View borrowed and available books
- View customer information

### Customer
- Search for books by title, author, or category
- View available books
- Borrow and return books
- View borrowed books

---

## Concepts Used
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance
- Encapsulation
- Polymorphism
- Exception Handling

---

- Designing classes and relationships
